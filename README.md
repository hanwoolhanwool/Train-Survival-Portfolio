# Train Survival Portfolio

Train Survival의 공개 포트폴리오 전용 저장소입니다. 게임 소스와 개발 이력은 별도 비공개 저장소에서 관리합니다.

- 메인: `index.html`
- 상세 페이지: `portfolio.html`, `nexon.html`, `performance.html`, `automation.html`
- 공개 이미지: `assets/`

GitHub Pages: `main` 브랜치의 루트(`/`)에서 게시합니다. 본문의 비공개 게임 저장소 링크는 권한이 있는 계정에서만 열립니다.
